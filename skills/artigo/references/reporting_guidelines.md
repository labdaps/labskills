# Reporting Guidelines (referencia rapida)

## TRIPOD+AI 2024 (predicao clinica via IA/ML)

Link: https://www.tripod-statement.org/

27 itens em 4 secoes:

### Title and Abstract
1. Title: identifica como modelo de predicao para diagnostico/prognostico, populacao alvo, desfecho, tipo (desenvolvimento/validacao)
2. Abstract: estruturado com objetivos, fonte de dados, desfecho, metodos, performance

### Introduction
3a. Background: contexto clinico
3b. Objetivos especificos

### Methods
4a. Source of data
4b. Eligibility criteria
5a. Outcome
5b. Predictors
5c. Sample size
5d. Missing data
6a. Algorithms
6b. Hyperparameter tuning
6c. Internal validation
6d. Performance measures
7. External validation (separado se houver)

### Results
8. Participants flow
9. Model development
10. Model performance
11. Model specification (entregar pesos ou regras se possivel)

### Discussion
12. Interpretation
13. Limitations
14. Implications

### Other
15. Funding
16. Code availability
17. Data availability
18. Ethics
19. Author contributions

**Especificos AI:**
- Bias e fairness: performance por subgrupos
- Reproducibilidade: versao de software, seeds, hardware
- Calibration explicita (nao so discriminacao)
- Decision curve analysis recomendado

## STROBE (observacionais)

22 itens. Versoes para coorte, caso-controle, transversal.

Pontos chave:
- Item 4: study design
- Item 6: participants e elegibilidade
- Item 7: variaveis e definicoes
- Item 9: bias controlados
- Item 10: study size
- Item 11: handling de variaveis quantitativas
- Item 12: metodos estatisticos (incluindo missing data, sensitivity analysis)
- Item 13-17: results (participants, descriptive, outcome, main results)
- Item 18-21: discussion, limitations, generalizability, funding

## PRISMA 2020 (revisoes sistematicas)

27 itens + flow diagram obrigatorio.

Secoes:
- Title, Abstract (PRISMA-A)
- Introduction (rationale, objectives)
- Methods: eligibility, sources, search strategy, selection process, data extraction, risk of bias, synthesis methods
- Results: study selection (com flow diagram), characteristics, risk of bias, results of individual studies, results of synthesis
- Discussion
- Other: registration (PROSPERO), funding, conflicts

Flow diagram obrigatorio: identification -> screening -> eligibility -> included.

## GRADE

Avaliacao de qualidade da evidencia em 4 niveis: alta, moderada, baixa, muito baixa.

5 dominios para downgrade:
- Risk of bias
- Inconsistency
- Indirectness
- Imprecision
- Publication bias

3 dominios para upgrade (observacionais):
- Large effect
- Dose-response
- Plausible confounding

## Como aplicar

1. Identificar o tipo de estudo
2. Baixar checklist do site oficial (ou EQUATOR Network)
3. Preencher item por item ANTES de submeter
4. Anexar como supplementary material
5. Citar a guideline no Methods: "We followed [GUIDELINE] reporting recommendations [REF]"
